EJEMPLO PARA SWAGGER — Jugo de mora en agua

Copia un objeto JSON por solicitud. El usuario, los identificadores internos,
el vencimiento y los valores del patrón son datos de prueba.

1. POST /api/usuarios
{
  "id": "2003",
  "nombre": "Laura Demo",
  "email": "laura.mora@example.com",
  "password": "NeveraMora2026!"
}

2. POST /api/usuarios/login
{
  "id": "2003",
  "password": "NeveraMora2026!"
}

Copia data.token y pégalo en Authorize.

3. POST /api/categorias
{
  "_id": "Pulpas de fruta"
}

4. POST /api/marcas
{
  "_id": "Coldfood"
}

5. POST /api/unidades_medida
{
  "_id": "Bolsa",
  "abreviatura": "bolsa"
}

6. POST /api/ingredientes
{
  "_id": "Pulpa de mora"
}

7. POST /api/productos
{
  "_id": "PROD-MORA-001",
  "marca_nombre": "Coldfood",
  "categoria_nombre": "Pulpas de fruta",
  "nombre": "Pulpa de mora congelada Coldfood, 250 g"
}

8. POST /api/inventario
{
  "user_nombre": "2003",
  "nevera_id": "NEVERA-01",
  "producto_id": "PROD-MORA-001",
  "unidad_medida_nombre": "Bolsa",
  "cantidad": 2,
  "fecha_vencimiento": "2027-01-15T23:59:00-05:00",
  "estado": "EN_NEVERA"
}

Guarda data._id para usarlo como itemId.

9. POST /api/patrones_predictivos
{
  "_id": "PATRON-MORA-001",
  "user_nombre": "2003",
  "frecuencia_compra_dias": 14,
  "probabilidad_desperdicio": 0.1
}

10. POST /api/meal_preps
{
  "patron_predictivo_id": "PATRON-MORA-001",
  "ingrediente_nombre": "Pulpa de mora",
  "nombre_receta": "Jugo de mora en agua"
}

11. POST /api/notificaciones
{
  "user_nombre": "2003",
  "mensaje": "Puedes aprovechar la pulpa de mora para preparar jugo con agua.",
  "tipo": "SUGERENCIA",
  "leida": false
}

12. PUT /api/usuarios/{id}
{
  "email": "laura.mora.actualizada@example.com"
}

Usa 2003 como id.

13. PUT /api/inventario/{itemId}
{
  "cantidad": 1
}

Usa el itemId del paso 8.

Ejemplos de consulta y borrado. Deja vacío el cuerpo de la solicitud.

GET /api/productos/PROD-MORA-001
GET /api/inventario?nevera_id=NEVERA-01&estado=EN_NEVERA
GET /api/patrones_predictivos/PATRON-MORA-001
GET /api/meal_preps
GET /api/notificaciones
GET /api/historial_inventario
GET /api/validaciones/productos/PROD-MORA-001
DELETE /api/inventario/{itemId}
