EJEMPLO PARA SWAGGER — Perro italiano con salchicha Zenú

Copia un objeto JSON por solicitud. El usuario, los identificadores internos,
el vencimiento y los valores del patrón son datos de prueba.

1. POST /api/usuarios
{
  "id": "2002",
  "nombre": "Camila Demo",
  "email": "camila.demo@example.com",
  "password": "NeveraZenu2026!"
}

2. POST /api/usuarios/login
{
  "id": "2002",
  "password": "NeveraZenu2026!"
}

Copia data.token y pégalo en Authorize.

3. POST /api/categorias
{
  "_id": "Embutidos"
}

4. POST /api/marcas
{
  "_id": "Zenú"
}

5. POST /api/unidades_medida
{
  "_id": "Paquete",
  "abreviatura": "paq"
}

6. POST /api/ingredientes
{
  "_id": "Salchicha"
}

7. POST /api/productos
{
  "_id": "PROD-ZENU-001",
  "marca_nombre": "Zenú",
  "categoria_nombre": "Embutidos",
  "nombre": "Salchicha Perro Caliente Zenú x6 (240 g)"
}

8. POST /api/inventario
{
  "user_nombre": "2002",
  "nevera_id": "NEVERA-01",
  "producto_id": "PROD-ZENU-001",
  "unidad_medida_nombre": "Paquete",
  "cantidad": 2,
  "fecha_vencimiento": "2026-12-05T23:59:00-05:00",
  "estado": "EN_NEVERA"
}

Guarda data._id para usarlo como itemId.

9. POST /api/patrones_predictivos
{
  "_id": "PATRON-ZENU-001",
  "user_nombre": "2002",
  "frecuencia_compra_dias": 14,
  "probabilidad_desperdicio": 0.2
}

10. POST /api/meal_preps
{
  "patron_predictivo_id": "PATRON-ZENU-001",
  "ingrediente_nombre": "Salchicha",
  "nombre_receta": "Perro italiano con salchicha Zenú"
}

11. POST /api/notificaciones
{
  "user_nombre": "2002",
  "mensaje": "Puedes usar las salchichas Zenú para preparar perros italianos con pan, tomate y queso.",
  "tipo": "SUGERENCIA",
  "leida": false
}

12. PUT /api/usuarios/{id}
{
  "email": "camila.demo.actualizada@example.com"
}

Usa 2002 como id.

13. PUT /api/inventario/{itemId}
{
  "cantidad": 1
}

Usa el itemId del paso 8.

Ejemplos de consulta y borrado. Deja vacío el cuerpo de la solicitud.

GET /api/productos/PROD-ZENU-001
GET /api/inventario?nevera_id=NEVERA-01&estado=EN_NEVERA
GET /api/patrones_predictivos/PATRON-ZENU-001
GET /api/meal_preps
GET /api/notificaciones
GET /api/historial_inventario
GET /api/validaciones/productos/PROD-ZENU-001
DELETE /api/inventario/{itemId}
